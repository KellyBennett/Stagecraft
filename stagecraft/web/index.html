Stagecraft / Match the camera

Human alignment

Drag the orange guides onto two edges that run parallel in the scene along one horizontal direction. Drag the cyan guides onto two edges along a perpendicular horizontal direction. Each pair must converge toward its own vanishing point. Use straight architectural edges, not shadows or curves.

Choose a reference plane below or above the camera. Place the purple origin on that plane, using a visible floor or overhead catwalk. This becomes world (0, 0, 0). Distance to the plane sets scale. The camera assumes an uncropped pinhole image with its optical center at the image center.

Tab to select a handle. Arrow keys move it one pixel; Shift + arrow moves ten. Guide extensions show convergence. Save overwrites the working controls and keeps this session open. Finish closes the session and resumes the CLI; run then exports the latest saved controls.
